# SavioERP Website - Internship Project

A professional website built for SavioERP during my internship. This project showcases a manufacturing ERP solution with responsive design and interactive features.

## Technologies Used

- Next.js 14 with App Router
- Tailwind CSS
- TypeScript
- Nodemailer for form submissions

## Features

- Responsive design for all devices
- Interactive module showcase
- Career portal with job applications
- Contact form with email integration
- Auto-scrolling hero section

## Setup

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Visit [https://savio-erp-live.vercel.app](https://savio-erp-live.vercel.app)

## Pages

- Homepage with hero section
- About page
- Modules showcase
- Career opportunities
- Client testimonials
- Contact form

This project was developed as part of my internship at SavioERP.
